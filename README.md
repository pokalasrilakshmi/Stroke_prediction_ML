Stroke Prediction using Machine Learning
live link : https://stroke-prediction-ai.streamlit.app/

📌 Overview

This project focuses on predicting the risk of stroke using machine learning algorithms based on patient health and lifestyle data. Stroke is a serious medical condition, and early risk detection can help in taking preventive measures and improving overall healthcare outcomes.

The model analyzes factors such as age, BMI, glucose level, hypertension, heart conditions, and smoking habits to estimate the probability of stroke.

✨ Features
Data preprocessing and transformation
Handling missing and inconsistent data
Conversion of categorical variables into numerical form
Model training and evaluation
Real-time prediction through user input
Interactive interface built with Streamlit
Visualization of prediction results
Basic suggestions based on risk level
🛠️ Tech Stack
Python
Pandas & NumPy
Scikit-learn
Matplotlib
Streamlit

Import dataset

The application is deployed using Streamlit, allowing users to input health details and instantly view stroke risk predictions.

To develop a predictive system that helps identify individuals at potential risk of stroke, supporting early intervention and better healthcare decisions.
